# Security

This is a private, single-user personal system (`docs/architecture/TDD.md` §38) — there is no
public signup and no external security-disclosure program. The threat model is maintained at
[`docs/architecture/THREAT_MODEL.md`](docs/architecture/THREAT_MODEL.md) and the source/AI
compliance boundary at [`core/SOURCE_POLICY.md`](core/SOURCE_POLICY.md).

If you are the operator and suspect a credential, session, or key compromise, start at
[`docs/runbooks/SECURITY_INCIDENT.md`](docs/runbooks/SECURITY_INCIDENT.md).
