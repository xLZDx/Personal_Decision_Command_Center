§1 Что было поручено

Поручение оператора: закончить G1 и параллельно подготовить манифесты областей для гейтов со второго по десятый. Второе выполнено полностью. Первое — нет, и ниже объясняется, почему оценка «осталось только подписать» была неверной.

Девять файлов написаны пятью агентами параллельно, каждый читал первоисточники сам. Они лежат в governance/plans/ как предложения, а не манифесты. Это не осторожность: governance/gate-manifests/README.md предписывает ровно этот маршрут своими словами — «Claude may propose a next-gate manifest as a non-binding artifact (e.g. in ../plans/), but it becomes binding only once the operator adopts/commits the actual file here». Связывающим манифест делает принятие оператором, по INV-28.

§3 Как они проверялись — и чего проверка не увидела

Сводку агента нельзя принимать за факт, поэтому все девять файлов прогнаны независимой проверкой, импортирующей настоящие parsePathList, compilePattern и checkScope из репозитория. Во всех девяти: allowed_paths непустой, все паттерны компилируются, ни одного vacuous **, обе обязательные отсечки авторитета на месте, и контрольная проба этих двух путей отбивается каждым файлом.

И эта проверка соврала. Она сказала «ok» по всем девяти, тогда как G8_MANIFEST_PROPOSAL.yaml был невалидным YAML: незакавыченный скаляр, содержащий : ", читается как разделитель ключа. Проверка этого не увидела, потому что читатель манифестов в репозитории — намеренно крошечный поднабор YAML, обходящий только два блока путей. То есть «проверено настоящим парсером» было утверждением шире стоящей за ним проверки — ровно тот дефект, который я ищу у других. Нашёл prettier, у которого парсер полный. Исправлено.

§4 BLOCKER: защита от удаления тестов слепа

scripts/verify/check-test-deletion.mjs существует, чтобы PR не мог тихо удалить или отключить тесты. Обе его половины ограничены расширением .test.ts: 

const TEST_FILE = /(^|\/)tests\/.*\.test\.ts$|\.test\.ts$/;
git diff -U0 BASE...HEAD -- '*.test.ts'

Обе ветви альтернативы заканчиваются на .test.ts, и второй проход ограничен тем же шаблоном. А корпус тестов проекта выглядит так:

Почему это дожило до сегодня — важнее самой ошибки. Эта защита — один из трёх отказных контролей, которые план ремедиации требует продемонстрировать на настоящем PR. Ни один из трёх никогда так не проверялся: они подтверждены только юнит-тестами, а те написаны на фикстурах .test.ts. Один прогон против реального корпуса репозитория вскрыл бы это немедленно.

§7 Что решает только оператор

R13 — модель учётных данных. Один admin-PAT делает всё. Варианты: сузить до fine-grained токена без admin; оставить и записать разделение как процедурное; вынести merge на отдельную личность. Решение про креденшелы — не моё.

Оставлять ли require_code_owner_review выключенным. Сейчас off, поэтому CODEOWNERS — декорация. Включить в лоб нельзя: при одной учётной записи автор PR = владелец кода = требуемый ревьюер, а GitHub запрещает апрув собственного PR.

Демонстрация отказа по хешу требует PR, в котором изменён манифест, — файл, к которому имплементеру нельзя прикасаться по INV-28. Такой PR не может быть смержен по построению, но трогать защищённый файл без прямого слова оператора я не стану.

Агенты подняли и предметные вопросы, ответ на которые меняет форму манифестов: где живёт AIContextBuilder; относится ли AI-извлечение к G3 или к G6 (ADR-005 и мастер-план расходятся); требует ли включение R2 платёжного средства — это прямая угроза HARD_ZERO для G8; и остаётся ли reports/*.html плоским против reports/gate-*/ из TDD §55.

§8 Что дальше

Порядок, утверждённый GPT-PM: G1 закрывается отдельно и первым, через собственный Gate: G1 PR под связывающим g1.yaml; предложения манифестов идут отдельным Gate: NONE PR и ничего из закрытия G1 не несут. Реализация G2 не начинается, пока G1 не закрыт и три preflight-условия не выполнены.

Ближайшая содержательная работа по G1 — починить защиту тестов вместе с регрессионным тестом, провести три отказных контроля на настоящих PR, исправить восемь устаревших утверждений и определить DoD для G1 либо зафиксировать его отсутствие как принятое отклонение.
