G2 pipeline architecture — proposal stage, pending GPT-PM

Per a new operator-mandated workflow (specialist agents propose → Claude verifies against primary sources → GPT-PM decides), four agents ran in parallel on the layer above the merged schema: type-design-analyzer, database-reviewer, code-architect, architect. Nothing has been implemented — no file under packages/, services/, or infra/migrations/ was created or edited as part of this proposal round.

Convergent finding — independently verified, not taken on an agent's word

All four agents independently found the same defect: the Processing Reconciler's query, as literally written in the binding spec (docs/architecture/TDD.md:840-846) and in ADR-006:40-44, mixes ingest_events.state values with processing_outbox's next_attempt_at/attempt_count columns and its own purpose-built index — unexecutable as a single index-covered query. Verified directly by reading all three files, not accepted on citation alone. Must be resolved before the migration is applied to any live D1 — SQLite cannot alter a CHECK constraint afterward.

Other verified findings

  • Attempt-cap invisibility: two of four proposals implement attempt_count < MAX as a literal SQL filter, which would leave a poison event permanently non-terminal and invisible to DLQ. Only architect's design (claim unconditionally, partition in memory) fixes it.
  • Package/service naming: architect's naming (packages/domain, policy, telemetry, testkit; services/ingest + services/processor) matches docs/architecture/TDD.md:2319-2381's own canonical repo layout exactly. code-architect invented packages/db/outbox/services/reconciler, none of which the spec names.
  • Open gap, unaddressed by all four: services/resolver is named in the spec's canonical layout and in ADR-011, but no proposal populates it.
  • queue_budget_counters check-then-increment race (confirmed against the migration's own comment); a devices table that breaks the migration's own stated scope-boundary rule; an open provenance-DAG multi-hop question against ADR-005; an unbounded routing_hints array; confirmation that CPU cannot be measured inside a Cloudflare Worker (Date.now() is frozen during compute).
